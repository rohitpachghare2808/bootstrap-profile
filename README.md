# Bootstrap Profile Page

A responsive personal profile page built with **Bootstrap 5** as part of my web development learning.

🔗 **Live site:** https://rohitpachghare2808.github.io/bootstrap-profile/

## Features

- Responsive navbar with a mobile hamburger menu
- Profile card with a 12-column grid layout
- Skill cards, alert and button components
- Contact form
- Modal popup and skill carousel

## Concepts practiced

- Spacing, colors, text and border utilities
- Grid system and responsive breakpoints
- Flexbox utilities
- Navbar, cards, alerts, forms, modal and carousel

## Built with

- HTML5
- CSS3
- Bootstrap 5.3 (CDN)

## Run locally

1. Clone the repo
2. Open `index.html` in your browser
